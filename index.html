    Mentés XML-be

    Ez ugyanaz az XML formátum, amit a HMs DIY Designer használ – ott megnyitható (Load), és innen is visszatölthető.

    Elrendezés megnyitása

    Válassz egy HMs DIY Designer XML fájlt, húzd az ablakra, vagy illeszd be a tartalmát. A jelenlegi elrendezést felülírja (visszavonható).

    Hogyan kerül az órára?

    Az adatmező egy kódolt „layout stringet” vár a beállításaiban. Ezt a karakterláncot jelenleg csak az eredeti (windowsos) HMs DIY Designer tudja előállítani, mert a kódolás nincs dokumentálva. A lépések:

    1. Itt: Mentés (XML) → töltsd le a fájlt.
    2. HMs DIY Designer: Load → nyisd meg az XML-t, majd Copy to clipboard (Ctrl+B).
    3. Garmin Connect / Garmin Express: a HMs DIY adatmező beállításaiban illeszd be a Default layout string mezőbe.

    Az előnézet betűi közelítések (a Garmin nem adja ki a készülékek betűtípusait), a grafikus elemek helye pontos. Az élő értékek helyén mintaértékek látszanak.

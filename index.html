    Open a layout

    Choose a project file (.json) or a HMs DIY Designer XML file, drop it on the window, or paste its contents or a layout string here (for example one copied from Garmin Connect). This replaces the current layout; Undo brings it back.

    Layout string for the device

      1. Copy the string with the button below.
      2. In Garmin Connect (phone) or Garmin Express, open the settings of the HMs DIY data field among the device's Connect IQ data fields.
      3. Paste it into Default layout string, save, then put the data field into a large enough field on an activity screen.

      The encoding is the generation "C" format of HMs DIY Designer 3.4.2. If the device shows "Incompatible string!", the data field expects another generation. An existing string can be loaded back by pasting it into the Open dialog.

      Change device

      Scaling moves and resizes every element in proportion. Font sizes are fixed per device, so text may need adjusting afterwards. Undo brings the old layout back.

      Choose a value

      M / H: needs a medium- or high-memory device

      Colour

      The 64 colours Garmin colour screens can show. Click one to use it.

      Other colours are rounded by the device to the nearest one it can display. When a colour is linked to a value (dynamic colour), its exact code is used as the key, so special key colours stay as they are.
